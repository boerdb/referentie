# CSL-stijlen en locales

Afkomstig uit de officiële repositories van het Citation Style Language-project:

- Stijlen: https://github.com/citation-style-language/styles (`vancouver.csl` is `nlm-citation-sequence.csl`)
- Locales: https://github.com/citation-style-language/locales

Licentie: Creative Commons Attribution-ShareAlike 3.0 (zie de `<rights>`-regel in elk bestand).
Opmaak gebeurt met citeproc-js (CPAL-1.0 / AGPL-1.0).

Een stijl toevoegen: zet het `.csl`-bestand hier neer en voeg het toe aan `lib/cite/styles.ts`.
